# Notification assets

`empty-bell.webp` is a standalone transparent illustration derived from the approved mockup with built-in ImageGen. It contains no interface or text. Its exact generation prompt and SHA-256 are in `manifest.json`.

The mint backdrop, leaf watermarks, cards, switch, filters, and controls are native CSS/HTML. Functional icons reuse Lucide. The dashboard shell, VERGO logo, and VERA mascot keep their existing assets.

Source PNG: `exec-e4c79b73-521e-4825-b9ff-b1bdbed3132d.png`. Downscaled to 480px WebP with alpha preserved.
