# Admin workspace illustrations

Two separate transparent illustrations adapted from the user's SLA and Community/Hermes mockups. They are decorative assets; all headings, statistics, filters, report data, decision controls, and icons remain native accessible components.

| File | Use | Dimensions |
| --- | --- | --- |
| `sla.webp` | Assignment and SLA header: clipboard, clock, green leaves | 640 × 480 |
| `hermes.webp` | Community review header: clipboard, magnifier, mint leaves | 640 × 480 |

Generated with the built-in image generation tool on 2026-10-18 using the corresponding user-supplied mockup as reference, then resized and encoded as WebP with Sharp. Both retain an alpha channel. See `manifest.json` for byte counts and checksums.

Generation direction: isolate the relevant header illustration from each supplied mockup; polished mint and emerald 2.5D material, soft light, no text, no UI screenshot, no frame, transparent background. Original PNGs remain in the local image-generation output directory and are not required at runtime.

Interface icons use the project's existing Lucide React icon system. Report thumbnails are shown only where the API provides real evidence images; decorative artwork never substitutes for report evidence.
